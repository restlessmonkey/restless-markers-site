    Add to Home Screen
    
        
    
          
    Safari on iPhone or iPad (no App Store)
    
          
    Open the Restless Markers website in Safari. After adding it to your Home Screen, you can launch it like an app. Marker data and the application shell are cached for offline use after they have been loaded.
    
          
    1. Tap the Share button in the toolbar (square with an arrow pointing up).
    2. Scroll the menu and tap Add to Home Screen.
    3. Tap Add in the top corner.
    
        
    
        
    
          
    If your browser supports it, you may see an Install icon in the address bar (Chrome or Edge), or use the browser menu to choose Install app / Add to Home Screen.
    
          
    Installing as an app usually requires HTTPS or localhost.
    
        
    
        
      
    
        

    
      
    
        
    About marker data updates
    
        
    
          
    This hosted app displays the marker dataset bundled with the current release. GitHub Pages cannot run the server-side updater that downloads fresh state marker data.
    
          
    Marker-data refresh and validation are performed in the private canonical Restless Markers source repository, then validated browser-ready files are published here. The public site repository intentionally does not contain the ingestion, audit, or reconciliation tooling.

    Source and accuracy
    Marker information is derived from public Texas Historical Commission data. This is an independent viewer, not an official Texas Historical Commission product. For the official record, use the Historic Sites Atlas.
    
        
    Privacy
    The application has no user accounts. Restless Markers does not currently send marker searches, selected markers, or precise device location as custom analytics events. Layout and last-selected-state preferences stay on your device. Optional location, address, and map features use your browser or third-party services only when requested.
